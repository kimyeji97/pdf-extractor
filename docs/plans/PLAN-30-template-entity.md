## 배경

문제집 생성 화면에서 표지·각주·워터마크를 **매번 따로** 고른다. REQ-29가 각주·워터마크를
더하면서 `editor/index.jsx`의 선택 칩 행이 **3줄**이 됐고, 미리보기 패널 헤더를 그만큼 먹는다.
같은 조합을 반복해 쓰는 사용자는 생성할 때마다 세 번 고른다.

## 범위

**포함**
- 템플릿 CRUD (`/api/templates`) — 표지 CRUD(`cover.py`)와 같은 모양, 이름 + 참조 id 3개
- `ExtractV2Request.template_id` 추가 — 기존 `cover_id`·`footnote_id`·`watermark_id`는 **유지**
- **요청 시점 참조 검증** — `template_id` 경로와 직접 id 경로 **양쪽**
- 표지·각주·워터마크 삭제 시 **참조 검사 + 명시적 강제 삭제**
- 강제 삭제로 구성이 바뀐 템플릿에 **`needs_review` 플래그 + "구성 변경됨 · 확인 필요" 칩**
- `WorkbookMeta.template_id` 저장 + 결과 → 편집 복원
- 프론트: 템플릿 관리 화면 4번째 탭, 생성 화면 칩 **3줄 → 1줄**

## 제약·함정

- ⚠️ **스토리지는 세 파일을 함께 고친다** — `storage.py`(팩토리) · `local_storage_service.py` ·
  `s3_service.py`. REQ-29 Phase 1 실측: 하나만 고치면 팩토리의 s3 분기가 `ImportError`로 죽는다.
  로컬 테스트는 계약 #24로 항상 local 백엔드라 **s3 경로는 이 환경에서 실행 검증이 안 된다**
  (구문 검사만). REQ-29가 같은 잔여 위험을 안고 있고, 이번 작업이 그 위에 쌓인다.
- ⚠️ **`pdf_service`의 `if meta:` 관대 처리는 지우지 않는다.** 요청 검증(E) 통과 후 백그라운드
  진입까지의 경쟁 상태가 있고, 거기서 죽는 것보다 낫다. 다만 **정상 경로에선 도달하지 않는
  자리**가 되므로 주석으로 그 사실을 남긴다 — 안 남기면 나중에 "이미 방어되어 있네" 하고 요청
  시점 검증을 걷어내 **조용히 빠진 PDF가 되돌아온다.**
- ⚠️ **빈 슬롯은 두 가지 뜻을 가진다** — "원래 안 넣었다"와 "지워져서 비었다". 저장된 값만으로는
  **구별할 수 없으므로** `needs_review`를 파생 판정으로 대체하려 하면 안 된다. 정상 템플릿에 칩이
  붙는 오탐이 난다.
- ⚠️ **경고 칩의 색은 `tintBg`/`tintSx`/`tintFg`로 낸다** — `error.lighter`·`warning.lighter`는
  라이트/다크가 공유하는 값이라 **다크에서 어두운 화면에 파스텔 블록이 박힌다.** 정상 토큰을 쓴
  것이라 grep으로 안 잡히고 콘솔·빌드도 조용하다(계약 #20). `tintSx`/`tintFg`는 **함수를 반환**하므로
  `sx={(theme) => ({ ...tintSx('warning')(theme) })}` 형태여야 한다 — 객체 sx에 스프레드하면
  아무것도 안 들어가고 에러도 안 난다.
- ⚠️ **`extract-v2`는 `template_id`가 이겨도 `cover_id` 등을 무시만 한다** — 400으로 거절하지
  않는다. 계약 #23과 같은 결로 **필드의 존재 여부가 동작을 가르므로**, `template_id`에 기본값을
  채우면 안 된다.
- ⚠️ **PLAN-29의 케이스 29-26~28은 이 작업에서 의도적으로 깨진다.** `/testrun`이 이걸 구현
  결함으로 분류하지 않도록 Phase 2 착수 전에 PLAN-29 검증 계약에 은퇴 표시를 먼저 한다.
  계약 #28과 같은 계열(테스트가 모듈 경로·소스 문자열에 묶여 있다).
- ⚠️ **`editor/index.jsx`·`format/index.jsx`는 렌더 무대가 없다**(API mock 5~6개 필요, D11·REQ-29
  로그와 같은 결론). 선택 배선은 소스 스캔으로, 요청 구성은 `global.fetch` 모킹(REQ-29 Phase 2가
  도입한 레이어)으로 덮는다.
- `workbook_name`이 고유하지 않듯(계약 #17) **템플릿 이름도 고유하지 않다** — 표지·각주·워터마크가
  전부 자유 입력이다. 식별·색 해시의 키는 항상 `template_id`로 한다.
