# PLAN-B16 · 문항 끝에 붙은 그림이 크롭에서 잘린다

> 출처: 2026-09-28 세션(dev 육안 제보 "3페이지 5번문항의 그래프 이미지가 잘렸다" → 원인 조사·수정·실측) · 작성: 2026-09-28 · 상태: ✅ 완료 (PR #19 main 머지 · dev 배포 2026-09-28 `c17f884`)

## 배경

dev에서 `0928 테스트4`(= 학교별 심화기출 Red) **3페이지 5번**의 문항 크롭이 본문 텍스트까지만
나오고 그 아래 삼각형 그림이 통째로 빠졌다.

하단 조임(`_calc_tight_y_bottom`, REQ-23 → REQ-B13)은 **문항에 속한 단어의 최대 bottom + 10pt**로
y_bottom을 정한다 — **텍스트만 본다.** 이 PDF의 그림은 **임베디드 이미지**라 단어 목록에 없다.
같은 페이지 4번·7번은 그림 **아래에 선지 텍스트가 있어서** 우연히 살았고, 5번은 그림으로 끝나서
잘렸다(실측: 텍스트 끝 483 → y_bottom 493, 이미지 494~614).

즉 **"그림으로 끝나는 문항"은 전부 잘린다.** 실제 기출 4종에서 92문항이 해당됐다(아래 Phase 1).

## 범위

**포함**
- 하단 조임 계산에 **그림 bbox(pdfplumber `images`·`rects`·`curves`·`lines`)**를 텍스트와 함께 넣는다
- 페이지 장식(머리말·꼬리말 띠, 단 구분선 같은 긴 선, 옆 단 박스 테두리)이 딸려 오지 않게 거른다

**제외**
- **좌·우·상 변** — 그림은 **하단 계산에만** 쓴다. x 정밀화·문항 번호 탐색은 종전대로 텍스트만 본다.
  그래서 **텍스트보다 오른쪽으로 넓은 그림은 여전히 우측이 잘릴 수 있다** — 실측 4종에서는
  발생하지 않아 이번엔 다루지 않는다 (2026-09-28)
- **기존 job 자동 재적용** — 경계는 `boundaries/{job_id}.json` 캐시라 **재감지(refresh)해야** 반영된다.
  일괄 마이그레이션은 하지 않는다(REQ-B13과 같은 방침)
- **"유형 N" 배지 오인식**(B13 Phase 2에서 발견한 기존 오탐) — 무관한 별개 이슈
