# PLAN-B26 · 문항 삭제 [되돌리기]가 복원하지 않음

> 출처: 2026-10-02 dev 전체 확인(사용자) · 작성: 2026-10-02 · 상태: 📝 초안

## 배경

- 오탐 문항 삭제 후 되돌리면 '오탐' 뱃지가 사라져 있다
- 수동 문항 삭제 후 되돌려도 다시 나타나지 않는다

원인: 삭제는 즉시 서버에 반영되고, [되돌리기]는 서버 목록을 다시 읽기만 한다(`QuestionAnalysisPanel` `fetchQuestions`).
아무것도 복원되지 않는다. 뱃지 없는 문항은 같은 쪽·같은 번호의 다른 문항이 남아 보인 것으로 추정(B18 공존 쌍).

## 범위

**포함** — 삭제를 4초 토스트 동안 미루고, 되돌리면 삭제 전 상태(오탐 표시 포함) 그대로

**제외** — 단건 삭제 외 편집(제목 수정 등)의 되돌리기 · 백엔드 변경
