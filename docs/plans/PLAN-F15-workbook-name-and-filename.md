## 배경

사용자는 파일을 **문제집 이름**으로 기억한다(업로드 때 붙이는 자유 입력 이름). 그런데 화면마다 보이는 이름이 다르다.

1. **알림(벨 팝오버·완료 스낵바)은 파일명**을 보인다 — 코드 확인: 감지 알림은 백엔드 `emit_detection`이 `title=job.filename`으로 쓴다.
   생성 알림(`emit_export`)은 이미 `workbook_name or job.filename`이다. 알림 제목은 **발행 시점에 저장**된다
2. **문제집 이름만 보이는 곳에서는 어떤 파일인지 알 수 없다** — 같은 이름이 여러 개일 수 있다(계약 #17: `workbook_name`은 고유하지 않다).
   코드 확인(2026-09-30):

   | 화면 | 지금 보이는 것 |
   |---|---|
   | 문항분석 목록 카드(`analysis/index.jsx` → `BookCard`) | 제목 = 문제집 이름(없으면 파일명), 부제 = 업로드 시각 |
   | 편집 화면 파일 목록(`FileListPanel`) | 문제집 이름 + **아래 작은 글씨로 파일명** — 이미 병기돼 있다 |
   | 작업 화면 헤더(`resolveDocumentName`) | 문제집 이름(없으면 파일명) |
   | 현황판 상세 목록(`StatCards`) | 문제집 이름(없으면 파일명) |
   | 삭제 확인 다이얼로그 | 문제집 이름(없으면 파일명) |
