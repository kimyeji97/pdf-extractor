# PLAN-F16 · 생성된 PDF 저장 — 브라우저 저장 위치 선택 창

> 출처: 2026-10-02 dev 전체 확인(사용자) · 작성: 2026-10-02 · 상태: 🟡 진행 (2026-10-03 코드·테스트 완료 · 리뷰 3회 · **dev 육안 남음**)

## 배경

PDF 생성이 끝나면 지금은 자동 다운로드(기본 폴더)만 한다. 저장 위치를 고르고 싶다.

## 범위

**포함** — 생성 완료 후 [다운로드] 버튼 → 브라우저 **기본 저장 위치 선택 창**(우리가 모달을 만들지 않음) → 저장하면 끝

**제외**
- 브라우저 새 탭으로 열기 · 완료 시 자동 열기 — "자동으로 브라우저에 열리는 건 제공하지 말자"(2026-10-02 사용자)
- 완료 시 자동 다운로드 — 버튼으로만 저장(같은 결정)
- 자체 경로 선택 모달

## 제약·함정

- 선택 창은 **사용자 클릭 안에서** 열어야 한다(비동기 대기 뒤 열면 거부) — 창부터 띄우고 그 뒤 PDF를 받는다
- PDF를 `fetch`로 받으므로 R2 공개 도메인의 **CORS**에 dev 오리진이 있어야 한다(버킷 설정, CLAUDE.md 배포 상태 참고)
- 사용자가 창을 취소하면(`AbortError`) 조용히 끝낸다
- 계약 #22 — 완료 시 부수효과는 `useJobCompletion` 콜백 안
