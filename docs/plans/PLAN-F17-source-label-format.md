# PLAN-F17 · 출처 문구 형식 "n번) 문제집. p쪽. 문항이름."

> 출처: 2026-10-02 dev 전체 확인(사용자) · 작성: 2026-10-02 · 상태: 📝 초안

## 배경

생성 PDF·미리보기의 문항 출처가 지금 "n번. 문제집이름. p3. 문항이름"이고, 업로드 때 문제집 이름을 안 넣은 파일은 이름이 빠진다.

## 범위

**포함** — 형식 "**n번) 문제집. p쪽. 문항이름.**" · 이름 없으면 파일명(확장자 제외) · **분석 목록 등 이름 표시에서도 확장자를 뺀다**

**제외** — 라벨 위치·글꼴

## 결정

| 항목 | 결정 | 근거 | 기각한 안 |
|------|------|------|-----------|
| 형식 | `1번) 심화대비. p3. 문항 유형 01.` — 번호 뒤 `)`, 끝에 `.` | 2026-10-02 사용자 요청 | 지금 형식 |
| 문제집 이름 없을 때 | 파일명에서 확장자를 뺀 것 | 2026-10-02 사용자 결정 "확장자 미표기 => 분석 목록에서 이름표기하는 것과 같은 규칙" | 이름 칸 생략 · `3쪽` 표기 |

## 미결 질문

- [x] ~~분석 목록은 확장자째 보여 준다 — 목록도 뺄지~~ → 확장자는 보여 주지 않는다(2026-10-02 사용자). 이름 표시 규칙(`resolveDocumentName`·목록 카드)과 출처 문구 모두 확장자 제외
