# PLAN-F20 · 튜토리얼

> 출처: 2026-10-22 세션 (`/todo` 튜토리얼 항목 + `/workplan` 질문 4건 + 로컬 육안 뒤 재설계 질문 3건) · 2026-10-23 dev 육안 피드백 5건 · 2026-10-23 dev 육안 질문 2건·피드백 1건(Phase 7) · 작성: 2026-10-22 · 상태: ✅ 완료 (2026-10-23, 브랜치 `feat/F20-tutorial` main 머지 전)

## 배경

신기능을 배포해도 사용자가 모른다. REQ-28 공유가 그 예다. 카드의 공유 버튼과 오른쪽 패널을 직접 찾아야 한다.
처음 가입한 사용자도 업로드에서 문제집 생성까지 흐름을 안내받을 곳이 없다.
한 번 닫은 안내를 나중에 다시 볼 방법도 없다.

## 범위

**포함**
- 로그인한 사용자가 앱 첫 화면에 들어오면 아직 안 본 튜토리얼을 띄운다
- 다시 보지 않기
- 이미 본 사용자가 목록에서 골라 다시 보기
- 첫 콘텐츠 2개
  - 기본 흐름: 업로드 → 감지 → 선택 → 생성
  - 공유 (REQ-28)
- (2026-10-22 로컬 육안 뒤 재설계) 전용 튜토리얼 화면과 기능 위주 콘텐츠 6묶음
  - 분석: 업로드 → 분석 현황판(상태 설명) → 문제집 정보 편집 → 분석 결과 확인·문항 편집(삭제·수정·수동 추가) → 재감지
  - 생성: 문항 선택 → 순서 편집 → 템플릿 선택 → PDF 생성과 다운로드
  - 결과: 다운로드 → 재편집
  - 템플릿 관리: 추가·수정·삭제 → 수정·삭제가 생성과 결과에 미치는 영향
  - 분석 결과 공유: 1개 공유 → 2개 이상 공유 → 권한 변경·회수
  - 알림과 튜토리얼: 알림 뱃지 → 튜토리얼 다시 보기
- (2026-10-23 dev 육안 피드백) 튜토리얼 화면 다듬기와 재촬영, 촬영 스크립트
  - 튜토리얼 화면에서 사이드바를 숨기고 로고를 따로 보인다
  - 슬라이드 설명을 한 줄에 사실 하나씩 목록으로
  - 다시 보기에서 [다음]·[이전]이 묶음 경계를 넘는다
  - 생성 묶음 4장과 튜토리얼 화면 그림(`notify-2`)을 다시 찍는다
  - 촬영 스크립트를 레포에 둔다
- (2026-10-23 dev 육안 질문) 목차로 고른 안 본 묶음에도 [다시 보지 않기]
  - 목차를 누르면 다시 보기로 바뀌어 버튼이 사라졌다. 안 본 묶음을 끄려면 자동 모드 순서를 따라가야 했다
  - 목차 2뎁스(슬라이드)의 현재 장이 글자색만 달라 잘 구분되지 않는다

**제외**
- 스포트라이트 투어(실제 버튼을 짚는 말풍선). 화면을 고칠 때마다 깨지고 라이브러리나 직접 구현이 필요하다 (2026-10-22 슬라이드 모달 선택)
- 서버 저장. 기기를 바꾸면 다시 뜨는 것을 감수한다 (2026-10-22 localStorage 선택)
- 로그인 화면 등 비로그인 화면 노출

## 제약·함정

- localStorage 읽기·쓰기는 try/catch로 감싼다. 사생활 보호 모드나 저장 차단에서 예외가 난다. 실패하면 "안 봄"으로 보고 화면은 정상 렌더
- 모달 테스트는 앱과 같은 `ThemeProvider` 아래에서 렌더한다 (계약 #25)
- 칩·뱃지를 새로 쓰면 `utils/badges.js`에서 가져온다 (계약 #36)
- 색조 배경은 `tintSx`/`tintBg`를 쓴다. `*.lighter`는 다크에서 파스텔이다 (계약 #20)
- 스크린샷은 화면을 고치면 낡는다. 기본 흐름·공유 화면을 바꾸는 REQ는 그 튜토리얼 그림도 다시 찍는다
- 스크린샷에 실사용자 이메일·파일명이 찍히지 않게 테스트 계정으로 찍는다. dev는 test@test.com (2026-10-22 사용자 지정)
- 튜토리얼 문구는 화면 코드와 짝이다. 화면 동작을 읽고 쓴다(리뷰 회차 0에서 공유 문구가 실제와 달랐다)
- 로컬은 작업 화면 PDF 미리보기가 401로 안 열린다(F16 TODO). 작업 화면 스크린샷은 dev에서 찍는다
- `/tutorials?auto=1` ↔ `/tutorials`처럼 쿼리만 바뀌는 이동은 화면을 다시 마운트하지 않는다. `SuspenseOutlet`의 key가 pathname이라 `useState` 초기값이 그대로 남는다. 모드를 쿼리로 가르면 그 값을 key로 써서 다시 마운트한다 (리뷰 회차 2 실측)
- 촬영 스크립트는 localhost 오리진으로 dev API를 못 부른다(CORS). dev 프론트에 없는 화면은 로컬 프론트 + 격리 Chrome `--disable-web-security`로 찍는다 (2026-10-23 실측)
- 빨간 테두리는 요소에 outline을 거는 대신 body 위 고정 박스로 그린다. 카드 조상의 `overflow:hidden`이 outline을 자른다 (2026-10-23)
- 노출 판정을 `NotificationSnackbar`처럼 레이아웃 밖에 두면 로그인 화면에도 뜬다. 로그인한 레이아웃 안에 둔다. `DashboardLayout`은 router에서 `RequireAuth` 안이다
