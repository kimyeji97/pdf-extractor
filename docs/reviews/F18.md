## [회차 0] (c) 메타 저장이 실패하면 PDF 가 고아가 된다 — **별도 REQ 로 이연**(사용자 결정)

생성 화면의 다운로드는 **`getStatus(exportJobId).download_url` 에서 직접** URL 을 얻었다 — 문제집 메타와 무관했다.
결과 화면의 `handleDownload` 는 **`wb.result_job_id`**, 즉 **문제집 행이 존재해야** 동작한다.

```python
except Exception as e:

    # 상태는 DONE으로 두고 사유만 남긴다.
```

**계획서가 이 경우를 정하지 않았다** — 결정이 조용히 뒤집힌 게 아니라 **고려되지 않은 것**이라 (c) 다.
