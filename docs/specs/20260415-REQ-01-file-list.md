## 1. 배경·목표

**배경**

v1은 업로드 후 문항 번호를 텍스트로 입력하는 방식이었다. v2 시각적 브라우징의 진입점으로, 스토리지에 업로드된 파일을 UI에서 직접 확인·선택할 수 있어야 한다.

**목표 / 달성 기준**

- 업로드된 파일 목록을 조회하여 파일명·업로드 시각·상태(PENDING/DONE 등)를 표시한다.
- 목록에서 파일 1개를 선택할 수 있다.
- 업로드 최신순으로 기본 정렬된다.

---

## 2. Scope

**In-scope**

- `GET /api/jobs` 목록 조회 API
- `FileListPanel` 목록 렌더링·단일 선택

**Out-of-scope (non-goal)**

- 페이지/문항 단계 탐색 (REQ-02, REQ-03)
- 업로드/생성 파일 섹션 분리 (REQ-08)

## 3. API·데이터 변경

### API

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/jobs` | 업로드된 job 목록. 항목별 `job_id`, 파일명, 업로드 시각, 상태 |

### 데이터 모델·스키마

`JobSummary` (응답 모델): `job_id`, 파일명, 업로드 시각, 상태.
