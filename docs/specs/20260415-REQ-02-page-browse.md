## 1. 배경·목표

**배경**

파일을 선택한 뒤 어떤 페이지에 어떤 문항이 있는지 시각적으로 확인할 수 있어야 한다.

**목표 / 달성 기준**

- 파일 선택 시 해당 PDF의 페이지 목록이 썸네일로 나열된다.
- 페이지 1개를 클릭하면 해당 페이지가 선택된다.
- 첫 썸네일 요청은 3초 이내, 반복 요청은 캐시 반환.

---

## 2. Scope

**In-scope**

- `GET /api/jobs/{id}/pages` 페이지 목록
- `GET /api/jobs/{id}/pages/{n}/thumbnail` 썸네일(PNG)
- `PageBrowser` 썸네일 그리드·단일 선택

**Out-of-scope (non-goal)**

- 페이지별 문항 수 표시 (REQ-09)
- 문항 단계 탐색 (REQ-03)

---

## 3. API·데이터 변경

### API

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/jobs/{job_id}/pages` | 페이지 수 및 썸네일 URL 목록 |
| GET | `/api/jobs/{job_id}/pages/{page_num}/thumbnail` | 페이지 썸네일 PNG |

### 데이터 모델·스키마

`page_num`은 0-based 인덱스.
