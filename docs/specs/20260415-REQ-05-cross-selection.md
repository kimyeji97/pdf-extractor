## 1. 배경·목표

**배경**

여러 파일/페이지를 오가며 문항을 누적 선택할 수 있어야 한 번에 다양한 출처의 문항으로 문제집을 구성할 수 있다.

**목표 / 달성 기준**

- 파일/페이지 선택을 바꿔도 기존 바스켓 항목이 유지된 채 새 문항이 추가된다.
- 같은 문항을 중복 추가할 수 없다.

---

## 2. Scope

**In-scope**

- 파일/페이지 전환 시 바스켓 상태 보존
- 중복 추가 방지(문항 식별자 기준)

**Out-of-scope (non-goal)**

- 새로고침 후 영속 복원(비-수동 문항은 React state 유지로 한정)
