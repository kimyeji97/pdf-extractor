## 1. 배경·목표

**배경**

바스켓에 모은 문항만으로 새 PDF를 생성·다운로드할 수 있어야 한다. 기존 번호 입력 방식(`/api/extract`)과는 별개로 동작한다.

**목표 / 달성 기준**

- 바스켓 문항만 모아 새 PDF를 생성(비동기)하고 다운로드한다.
- 문항 순서는 바스켓 표기 순서를 따른다.

---

## 2. Scope

**In-scope**

- `POST /api/extract-v2` 비동기 PDF 생성
- `ExportButton` 트리거·다운로드

**Out-of-scope (non-goal)**

- 그리드 레이아웃 지정 (REQ-18, v3)
- 생성 이력 관리 (REQ-21)

---

## 3. API·데이터 변경

### API

| Method | Path | 설명 |
|--------|------|------|
| POST | `/api/extract-v2` | 선택 문항 목록으로 PDF 생성(비동기), `result_job_id` 반환 |

### 데이터 모델·스키마

요청: 선택 문항 목록(파일/페이지/문항). 결과는 생성 파일(job)로 저장.

### 마이그레이션 메모

기존 `/api/extract`와 병존.
