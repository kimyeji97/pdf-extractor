## 1. 배경·목표

**배경**

사용자가 업로드한 원본과 추출로 생성된 결과 PDF가 한 목록에 섞이면 혼란스럽다.

**목표 / 달성 기준**

- 파일 목록을 원본 파일 섹션과 생성 파일 섹션으로 분리 표시한다.
