## 1. 배경·목표

**배경**

감지 로직 개선·문서 특성에 따라 문항을 다시 감지해야 할 수 있다.

**목표 / 달성 기준**

- 파일 선택 후 해당 파일의 문항 경계 재감지를 실행할 수 있다.
- 재감지 결과가 캐시에 반영되고 UI에 갱신된다.

## 2. Scope

**In-scope**

- 파일 단위 재감지 트리거 API
