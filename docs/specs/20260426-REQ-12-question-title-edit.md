## 1. 배경·목표

**배경**

자동/수동 문항에 사용자가 식별하기 쉬운 이름을 부여할 수 있어야 한다.

**목표 / 달성 기준**

- 자동 문항·수동 문항의 타이틀을 수정·저장할 수 있다.
- `title`이 `null`이면 "문항 {number}"로 표시한다.

---

## 2. Scope

**In-scope**

- 자동/수동 문항 타이틀 PATCH API
- 타이틀 인라인 편집 UI

**Out-of-scope (non-goal)**

- 수동 문항 생성 (REQ-13)

---

## 3. API·데이터 변경

### API

| Method | Path | 설명 |
|--------|------|------|
| PATCH | `/api/jobs/{id}/pages/{n}/questions/{q}` | 자동 문항 타이틀 수정 |
| PATCH | `/api/jobs/{id}/pages/{n}/questions/manual/{mid}` | 수동 문항 타이틀 수정 |

### 데이터 모델·스키마

문항 응답에 `title` 필드 추가. 자동 문항 타이틀은 별도 저장(또는 boundary 확장).

### 마이그레이션 메모

기존 캐시는 `title=null` 기본값으로 역직렬화.
