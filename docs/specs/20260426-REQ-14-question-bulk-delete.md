## 1. 배경·목표

**배경**

오탐지·불필요 문항을 선택해 한 번에 제거할 수 있어야 한다.

**목표 / 달성 기준**

- 문항들을 선택해 일괄 삭제할 수 있다(자동·수동 모두).

---

## 2. Scope

**In-scope**

- 자동/수동 문항 DELETE API
- 다중 선택 후 삭제 UI

**Out-of-scope (non-goal)**

- 삭제 취소(undo)

---

## 3. API·데이터 변경

### API

| Method | Path | 설명 |
|--------|------|------|
| DELETE | `/api/jobs/{id}/pages/{n}/questions/{q}` | 자동 문항 삭제 |
| DELETE | `/api/jobs/{id}/pages/{n}/questions/manual/{mid}` | 수동 문항 삭제 |

### 데이터 모델·스키마

자동 문항 삭제 마킹(또는 캐시에서 제외), 수동 문항은 `manual_questions/{job_id}.json`에서 제거.
