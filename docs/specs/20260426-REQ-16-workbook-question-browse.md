## 1. 배경·목표

**배경**

문제집 생성 메뉴에서 파일 → 페이지 → 문항(타이틀 기반 목록)을 탐색하며 문항을 선택할 수 있어야 한다.

**목표 / 달성 기준**

- 파일·페이지·문항을 단계적으로 탐색하고 타이틀 기반 목록에서 선택한다.
