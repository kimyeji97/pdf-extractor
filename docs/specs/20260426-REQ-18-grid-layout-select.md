## 1. 배경·목표

**배경**

문제집 페이지를 여러 칸으로 나눠 문항을 배치할 수 있어야 한다.

**목표 / 달성 기준**

- 페이지 레이아웃을 선택한다: 2단(1×2) / 4단(2×2) / 6단(3×3).
- 선택 레이아웃이 미리보기·생성 PDF에 반영된다.

> v3.1에서 명칭·구성 변경: REQ-C02(6단 2×3), REQ-C03(세로 2단), REQ-C04(가로 2단).
