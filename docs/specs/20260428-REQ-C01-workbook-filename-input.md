## 1. 배경·목표

**배경**

문제집 생성 시 파일명을 지정할 수 없어 결과 파일 구분이 어려웠다.

**목표 / 달성 기준**

- 생성 시 파일명을 입력받는다(기본값 `문제집_YYYY-MM-DD`).

---

## 2. Scope

**In-scope**

- 파일명 입력 UI + `extract-v2`/`workbooks` 스키마 반영

**Out-of-scope (non-goal)**

- 레이아웃 변경 (REQ-C02~C06)

---

## 3. API·데이터 변경

### API

`POST /api/extract-v2` / `POST /api/workbooks` 요청에 파일명 필드.

### 데이터 모델·스키마

`WorkbookMeta.name`, 결과 파일명 = 입력값.
