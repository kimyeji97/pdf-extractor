## 1. 배경·목표

**배경**

파일 선택 패널과 페이지 선택 패널이 분리돼 화면이 분산됐다. 하나의 섹션에서 단계 전환되도록 통합한다.

**목표 / 달성 기준**

- 파일 선택 후 동일 영역이 페이지 선택 모드로 전환되고, 뒤로가기로 복귀한다.
- 페이지 선택 모드에서는 썸네일 없이 감지 문항 수만 표시한다.
- 페이지 선택 시 두 번째 섹션에 전체 썸네일을 표시한다.
- `[수동 추가]` 버튼을 두 번째 섹션으로 이동한다.
