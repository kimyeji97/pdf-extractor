## 1. 배경·목표

**배경**

오탐지 의심(`is_false_positive`) 문항은 체크박스가 비활성 상태로 표시되어 선택할 수 없고, 그 결과 삭제도 불가능하다.

**목표**

- 오탐 의심 문항도 선택·삭제할 수 있다.

---

## 2. Scope

**In-scope**

- 오탐 의심 문항의 체크박스 활성화
- 오탐 문항 삭제 흐름 연결 (REQ-B06 벌크 삭제와 정합)

**Out-of-scope (non-goal)**

- 오탐 판정 알고리즘 변경

## 3. 수정 내용

### 정책 결정

문항 분석 패널(`QuestionAnalysisPanel`)의 체크박스는 **삭제 전용**이다(추출·바스켓 담기는 문제집 편집 화면의 별도 패널). 따라서 "추출 제외" 개념은 이 화면에 적용되지 않으며, 오탐 문항 카드에 이미 표시되는 안내문(*"오탐지일 수 있습니다. 문항 이미지를 확인 후 필요하면 삭제하세요."*)의 의도를 그대로 살린다.

- **개별 선택·삭제 활성화**: 오탐 문항 체크박스를 활성화해 사용자가 이미지를 확인한 뒤 선택하여 삭제할 수 있게 한다. (버그 직접 해소)
- **전체 선택에도 포함**: `allCheckable = questions`(오탐 포함)로 두어 "전체 선택/해제" 및 벌크 삭제(REQ-B06) 대상에 오탐 문항도 포함한다.

> **정책 변경 이력**: 최초에는 옵션 ①(개별 선택만 허용, 전체 선택에서 제외)로 구현했으나, 사용자 요청에 따라 **옵션 ②(완전 일반 취급)** 로 전환 — 오탐 문항도 전체 선택→벌크 삭제가 가능해야 한다. 시각적 경고(오탐 배지·안내문)는 그대로 유지되어 오분류 문항은 사용자가 육안으로 식별할 수 있다.

### 파일 / 변경

**`frontend/src/components/QuestionAnalysisPanel.jsx`** — 오탐 문항 체크박스 활성화

```jsx
// Before
<input type="checkbox" className="qap-card-check"
  checked={isChecked}
  onChange={() => !q.is_false_positive && toggleCheck(q.question_id)}
  disabled={q.is_false_positive}
  title={q.is_false_positive ? "오탐지 의심 문항은 직접 확인 후 삭제하세요." : ""}
/>
// After
<input type="checkbox" className="qap-card-check"
  checked={isChecked}
  onChange={() => toggleCheck(q.question_id)}
  title={q.is_false_positive ? "오탐지 의심 문항입니다. 이미지를 확인한 뒤 선택하여 삭제할 수 있습니다." : ""}
/>
```

삭제 흐름(`handleDeleteSelected`)은 체크된 항목을 그대로 삭제하며, 오탐 문항은 자동 감지 문항이므로 기존 `deleteQuestion(jobId, pageNum, question_num)` 경로로 정상 삭제된다 — 로직 변경 불필요.

> 오탐 문항의 **타이틀 인라인 편집**(더블클릭) 가드는 select/delete 범위 밖이라 유지(변경하지 않음). 오탐 배지·안내문도 시각적 경고로 그대로 유지.
