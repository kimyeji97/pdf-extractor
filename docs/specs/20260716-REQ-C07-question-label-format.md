## 1. 배경·목표

**배경**

문제 이미지 위에 표시하는 라벨(이하 "문항 라벨")의 포맷을 변경한다.

- as-is: `{번호}. {문제집이름} p{페이지 번호}`
- to-be: `{번호}. {문제집이름} p{페이지 번호} {문항 이름}`

**목표**

- 문항 라벨에 문항 이름을 포함하여 표시한다. (프론트 미리보기 + 생성 PDF 동일)

## 2. Scope

**In-scope**

- 라벨 문자열 조립 로직 변경 (프론트 `WorkbookPreview` + 백엔드 `pdf_service`)

**Out-of-scope (non-goal)**

- 라벨 위치/스타일 전면 재설계

## 3. 수정 내용

라벨 문자열을 프론트·백엔드가 **동일 문항 이름**을 쓰도록 통일한다. 프론트가 보내는 `SelectionItem.label`(= 편집 화면 `displayTitle`)을 단일 출처로 삼는다.

### 프론트 — `pages/editor/index.jsx`

- `toggleSelection`의 `displayTitle` 정리: 기존 `q.title || (…) + " · {page}p"`는 연산자 우선순위 때문에 이름 없는 문항에만 " · Xp" 접미사가 붙는 불일치가 있었다. → `q.title || (is_manual ? "(수동 문항)" : "문항 N")`로 정리(페이지 접미사 제거). 복원 경로는 이미 동일 형태라 무변경.

### 프론트 — `components/WorkbookPreview.jsx`

- 라벨 조립에 `item.displayTitle` 추가:
  `[{n}번, workbookName?, p{page}, displayTitle] .join(". ")`

### 백엔드 — `services/pdf_service.py`

- 기존에 무시하던 `sel.label`을 라벨에 추가(비어있지 않을 때):
  `label_parts = [f"{q_global}번", wb_name?, page_label, sel.label?]`
- 프론트가 보낸 이름을 그대로 사용 → **미리보기 == PDF** 문자열 일치 보장.

> to-be 포맷: `{번호}번. {문제집이름}. p{페이지}. {문항 이름}` ("데이터 보안" 논점은 예정된작업 원문의 `+ {문항 이름}`(추가) 의도로 확정 — 문제집 이름 제거가 아니라 문항 이름 추가).
