## 1. 배경·목표

**배경**

표지 관리(CoverFormatView)를 문항 분석의 **목록(상세 아님) 페이지**와 디자인을 통일한다. 예정된작업 방향은 다음과 같다.

- 2패널 → 1패널: `[+표지 업로드] [표지1] [표지2] [표지3] ...`
- `+표지 업로드` 클릭 시 모달로 업로드

> ⚠️ 기존 REQ-D05는 "2패널 수평 레이아웃"으로 작성되어 본 요구(1패널)와 상충한다. D05 폐기/대체 여부를 착수 시 확정한다.

**목표**

- 표지 관리를 목록형 1패널 + 업로드 모달로 재설계하여 목록 페이지와 디자인을 통일한다.

---

## 2. Scope

**In-scope**

- CoverFormatView를 1패널 목록형으로 변경
- `+표지 업로드` 카드 → 업로드 모달

**Out-of-scope (non-goal)**

## 4. 수정 내용

### (1) 표지 페이지 재작성 — `pages/format/index.jsx`

2패널(D05: ① 업로드 패널 + ② 목록 패널 + 리사이즈 핸들)을 **1패널 래핑 그리드**로 전면 교체.

- 상단 헤더 바(제목 "표지 관리" + 새로고침) — 문항 분석 목록 페이지와 동일 구조.
- 메인: `display:flex; flexWrap:wrap; overflowY:auto` 래핑 그리드. **`UploadCard`(+ 표지 업로드)가 항상 맨 앞**, 이어서 `CoverCard` 나열.
- 카드 규격을 분석 목록 페이지와 통일(`CARD_W 180 × CARD_H 280`, 썸네일 232 + 이름 48). 삭제 버튼은 hover 시 노출.
- 업로드는 **모달(`Dialog`)**로 분리: 드롭존(클릭 + 드래그&드롭) + 미리보기 + 표지 이름 + 업로드 버튼. 파일 미선택 시 업로드 버튼 disabled.
- 백엔드 API(`listCovers`/`uploadCover`/`deleteCover`) **무변경** 재사용.

### (2) 분석 목록 페이지 통일 — `pages/analysis/index.jsx`

디자인 통일을 위해 기존 **가로 스크롤 한 줄**(`overflowX:auto; flexDirection:row`)을 **여러 줄 래핑 그리드**(`flexWrap:wrap; overflowY:auto; alignContent:flex-start`)로 변경. `UploadCard`/`JobCard` 배치·규격은 유지.

### (3) REQ-D05 대체 처리

D05 스펙은 파일을 이력으로 유지하되 상단에 **superseded 표기** 추가(상태 `open → superseded (→ REQ-D06)`). 실제 구현물은 본 스펙으로 대체.
