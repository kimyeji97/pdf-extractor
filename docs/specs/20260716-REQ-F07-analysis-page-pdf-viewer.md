---

## 1. 배경·목표

**배경**

문항 분석 화면의 페이지 미리보기는 현재 페이지 썸네일 방식(`FilePagePanel`/`PageBrowser`)을 사용한다. 생성 이력(REQ-F06)에서 도입한 PDF 뷰어처럼 실제 PDF를 렌더링하는 방식으로 통일한다.

**목표**

- 문항 분석 페이지 미리보기를 PDF 뷰어(`PdfPreviewPanel` 재사용)로 전환
- 확대/축소, 페이지 이동, 스크롤 탐색 제공

---

## 2. Scope

**In-scope**

- 문항 분석 페이지 미리보기 패널을 PDF 뷰어로 교체
- 문항 선택·드래그 오버레이를 PDF 렌더 좌표계 위에서 동작하도록 조정

**Out-of-scope (non-goal)**

- 문항 감지 알고리즘 변경
- 백엔드 문항 경계 데이터 구조 변경

---

## 3. 수정 내용

> 착수 시 작성. 좌표계 변환 설계가 핵심.

---

## 4. 테스트 시나리오

| # | 시나리오 | 기대 결과 |
|---|----------|-----------|
| 1 | 파일 선택 → 페이지 미리보기 | PDF 뷰어로 렌더 |
| 2 | 문항 선택/드래그 | 오버레이가 PDF 위 정확한 위치에 표시 |
| 3 | 확대/축소 후 문항 선택 | 배율과 무관하게 좌표 정합 |

---

## 5. 미결 질문 (Open Questions)

- 소스 `original.pdf`를 뷰어에 넘길 서빙 경로 확정 (`/api/files/...`)
- 문항 선택·드래그 오버레이 좌표계를 썸네일 기반 → PDF 렌더 좌표계로 변환하는 방법 (⚠️ 최대 난제)
- 기존 `FilePagePanel`/`PageBrowser`를 어디까지 대체/유지할지
- REQ-P02 뷰어 가상화와 겹침 → 함께 설계 필요
- REQ-B05(뷰어 툴바)와 컴포넌트 공유 범위 정합
